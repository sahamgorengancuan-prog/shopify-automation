# Deployment notes

Generated by the ARCHIVIST Deploy tab.

## Docker

    docker compose -f docker-compose.yml up -d --build
    # open http://localhost:7860

Runs and the collection style lock live in the `archivist-runs` volume.

## systemd (Ubuntu 24.04)

    sudo cp archivist.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now archivist
    journalctl -u archivist -f

## Windows (start at logon)

    schtasks /Create /TN ARCHIVIST /XML windows-task.xml

## Hugging Face Space

Copy `space_app.py`, `README.md`, `requirements.txt` and the `archivist/` package
into a new Gradio Space, then add your API keys as Space secrets.

## Exposing it

`--share` gives a temporary public Gradio URL — convenient, but it forwards to
your machine, so only use it for a demo. For anything permanent put the app
behind a reverse proxy with TLS and basic auth, or run
`python -m archivist.app --auth user:password`.
